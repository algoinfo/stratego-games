# Field Manual Stratego

Unofficial English-language Classic Original Stratego strategy guide and wiki. Content-only — no playable game, multiplayer, or fake stats.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```
